# Synerbit Admin Console

Enterprise Ecosystem Management & Role-Based Access Control (RBAC) console for **Synerbit (OPC) Private Limited**.

## Key Modules
- **Products Manager**: Manage software ecosystem items, release status (Live, Beta, In Development), platform badges, and links.
- **Jobs & Careers Manager**: Post job openings, manage departments, employment types (Full time, Part time, Internship, Live Project), and salary specifications.
- **Applications Inbox**: Review, screen, and manage candidates applying for roles.
- **Idea Incubation Lab**: Review and evaluate SaaS ideas submitted by users.
- **Contact Inquiries**: Triage, respond to, and manage contact messages from the landing website.
- **RBAC & Team Access**: Control admin roles, permissions, and team member access.
- **Firebase Integration**: Live synchronization with Firebase Firestore & Storage, with automated offline local persistence fallback.

## Quick Start
```bash
# Install dependencies
npm install

# Start development server (Port 5174)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
